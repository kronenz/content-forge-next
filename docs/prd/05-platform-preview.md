# 플랫폼별 프리뷰 시스템

## 개요

콘텐츠가 실제 발행되었을 때 각 플랫폼에서 어떻게 보이는지를 발행 전에 정확하게 미리 볼 수 있는 시스템입니다. 품질, 정확도, human-like 수준, 플랫폼 적합성을 검토하기 위한 핵심 기능입니다.

## 프리뷰 기능 상세

### 반응형 프리뷰
- **Desktop / Tablet / Mobile** 세 가지 뷰포트로 전환
- 각 플랫폼의 실제 레이아웃, 폰트, 색상 시스템 재현
- 다크모드 / 라이트모드 전환

### 실시간 편집 + 프리뷰
- 프리뷰 화면에서 직접 텍스트 수정 가능 (인라인 에디팅)
- 수정 즉시 프리뷰에 반영 (WYSIWYG)
- 글자 수 카운터 (플랫폼 제한에 맞춰 실시간 표시)

### OG (Open Graph) 미리보기
- 링크 공유 시 표시되는 OG 카드 미리보기
- 플랫폼별 OG 카드 차이 확인 (Facebook, Twitter, LinkedIn, Slack, KakaoTalk 등)
