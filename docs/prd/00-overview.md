# Content Forge - 서비스 개요

## 한 줄 정의

AI Agent 기반 콘텐츠 수집-가공-발행 자동화 플랫폼

## 비전

AI 시대에 흩어져 있는 정보를 신뢰도 높은 소스로부터 수집하고, AI Agent 파이프라인이 콘텐츠 발행사처럼 조직적으로 가공하여, 다양한 플랫폼에 최적화된 형태로 발행하는 올인원 콘텐츠 포지(Forge) 서비스.

## 핵심 가치

| 가치 | 설명 |
|------|------|
| **자동화** | 수집부터 발행까지 파이프라인 자동화, 반복 업무 제거 |
| **품질 보증** | 다단계 AI Agent 검증 + 사람 검토의 하이브리드 QA |
| **멀티 플랫폼** | 하나의 소스에서 블로그, LinkedIn, Instagram, X 등 각 플랫폼에 맞는 포맷 자동 생성 |
| **투명성** | 파이프라인 각 단계의 중간 데이터와 흐름을 실시간으로 확인 가능 |
| **점진적 자동화** | 검토를 통해 신뢰도가 올라가면 자동 승인으로 전환 |

## 타겟 사용자

### 1차 타겟: 개인 브랜딩 크리에이터
- 전문 지식을 가진 개인이 여러 플랫폼에 일관된 콘텐츠를 발행하고 싶은 경우
- 직접 글을 쓰기보다 큐레이션 + AI 가공으로 효율을 높이고 싶은 경우

### 2차 타겟: 소규모 마케팅 팀 / 에이전시
- 클라이언트별 다수 채널 운영
- 콘텐츠 생산 파이프라인의 체계화 필요

### 3차 타겟: SaaS 구독자
- Content Forge를 구독하여 자신만의 콘텐츠 파이프라인을 구축하는 일반 사용자

## 핵심 워크플로우

```
[소스 등록] → [자동 수집] → [AI 파이프라인 가공] → [프리뷰 & 검토] → [발행]
     ↑              ↑              ↑                    ↑              ↑
   사용자         스케줄러      Agent 체인         승인/수정        API 연동
                + Research      (편집국 조직)      (자동승인 옵션)
```

## 차별화 포인트

1. **편집국 메타포**: AI Agent들이 기자-에디터-편집장처럼 역할 분담
2. **파이프라인 가시성**: 각 단계의 중간 산출물을 투명하게 확인
3. **플랫폼 네이티브 프리뷰**: 발행 전 실제 플랫폼과 동일한 모습으로 미리보기
4. **신뢰도 기반 자동화**: 반복 검증을 통해 자동 승인 레벨을 점진적으로 올림
5. **Research Agent**: Claude API, Exa.ai 등을 활용한 능동적 정보 수집
