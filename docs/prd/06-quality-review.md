# 품질 검토 및 승인 시스템

## 개요

파이프라인을 통해 가공된 콘텐츠의 품질을 다차원적으로 평가하고, 검토 결과에 따라 승인/반려/수정을 결정하는 시스템입니다. 반복 검토를 통해 신뢰도가 올라가면 자동 승인 기능을 활성화할 수 있습니다.

## 품질 평가 차원

### 5대 품질 지표

| 지표 | 설명 | 평가 기준 |
|------|------|----------|
| **Quality (품질)** | 전반적인 콘텐츠 완성도 | 구조, 논리성, 가독성, 문법 |
| **Accuracy (정확도)** | 사실 관계의 정확성 | 출처 검증, 수치 확인, 인용 정확성 |
| **Human-like** | 사람이 쓴 것 같은 자연스러움 | 톤, 표현, 감정, 개성, AI스러움 탈피 |
| **Platform-fit** | 플랫폼 특성에 맞는 정도 | 포맷, 길이, 해시태그, 미디어 활용 |
| **Culture-fit** | 문화적 적합성 | 현지 트렌드, 표현, 감성, 맥락 |

### 상세 채점 기준 (각 10점 만점)

#### Quality (품질)
- 10: 전문 작가 수준, 바로 발행 가능
- 8-9: 높은 품질, 사소한 수정 필요
- 6-7: 양호, 일부 구조/논리 개선 필요
- 4-5: 미흡, 상당한 수정 필요
- 1-3: 재작성 필요

#### Human-like
- 10: AI가 쓴 티가 전혀 나지 않음
- 8-9: 자연스러움, 가끔 패턴이 보임
- 6-7: 대체로 자연스러우나 일부 AI스러운 표현
- 4-5: AI가 쓴 티가 남, 톤이 기계적
- 1-3: 명확히 AI 생성 콘텐츠로 인식됨

## 검토 워크플로우

```
┌───────────┐     ┌───────────┐     ┌───────────┐
│  AI 자동  │────▶│  사람 검토 │────▶│  최종 결정 │
│  사전 평가 │     │ (선택적)  │     │           │
└───────────┘     └───────────┘     └───────────┘
      │                 │                 │
      ▼                 ▼                 ▼
 자동 점수 산출    수동 점수 조정     승인 / 반려 / 수정 요청
 (5개 지표)      + 피드백 작성
```

### 1단계: AI 사전 평가
파이프라인의 Editor Agent가 자동으로 품질 점수를 산출합니다.

```yaml
auto_evaluation:
  quality: 8.5
  accuracy: 9.0
  human_like: 7.5
  platform_fit: 8.0
  culture_fit: 8.5
  overall: 8.3
  flags:
    - type: "warning"
      message: "2번째 문단의 통계 수치 출처 불명확"
    - type: "suggestion"
      message: "도입부 hook을 더 강하게 하면 engagement 향상 예상"
  ai_detection_score: 0.15  # 낮을수록 human-like (GPTZero 등 기반)
```

#### 인라인 피드백
- 프리뷰 위에서 특정 텍스트를 선택하여 직접 코멘트
- 하이라이트 + 코멘트 형식
- 수정 사항을 직접 입력하면 Writer Agent가 반영

### 3단계: 결정

| 결정 | 설명 | 이후 처리 |
|------|------|----------|
| **승인** | 발행 가능 | 발행 큐에 추가 |
| **수정 요청** | 특정 부분 수정 필요 | 피드백과 함께 Writer/Editor에게 재전달 |
| **반려** | 품질 미달 | 원본부터 재가공 또는 폐기 |

## 자동 승인 시스템

### 신뢰도 기반 자동 승인

반복적인 검토를 통해 파이프라인의 품질이 검증되면, 자동 승인을 활성화할 수 있습니다.

#### 자동 승인 조건 설정
```yaml
auto_approval:
  enabled: true
  conditions:
    min_quality_score: 8.0
    min_accuracy_score: 8.5
    min_human_like_score: 7.5
    min_platform_fit: 8.0
    min_culture_fit: 7.5
    max_ai_detection: 0.2    # AI 탐지 점수 상한
    no_critical_flags: true  # 심각한 경고가 없을 것

  # 자동 승인 대상 범위
  scope:
    pipelines: ["quick-linkedin", "blog-standard"]  # 특정 파이프라인만
    platforms: ["linkedin", "twitter"]               # 특정 플랫폼만
    source_groups: ["verified-sources"]              # 검증된 소스 그룹만

  # 안전장치
  safeguards:
    daily_auto_limit: 10        # 하루 자동 승인 최대 수
    require_manual_review_ratio: 0.2  # 20%는 반드시 수동 검토
    alert_on_score_drop: true   # 점수 하락 추세 감지 시 알림
    rollback_threshold: 3       # 연속 3회 사후 품질 미달 시 자동 승인 중지
```

#### 신뢰도 레벨
```
Level 0: 전체 수동 검토 (초기)
  → 모든 콘텐츠를 사람이 검토

Level 1: AI 사전 필터링 (20회 이상 검토 후)
  → AI 점수 기준 미달만 수동 검토로 라우팅
  → 기준 충족 시 "추천 승인" 표시 (클릭 한 번으로 승인)

Level 2: 조건부 자동 승인 (50회 이상 검토 후)
  → 조건 충족 시 자동 승인
  → 20% 샘플링 수동 검토

Level 3: 완전 자동화 (100회 이상 + 높은 사후 품질)
  → 거의 모든 콘텐츠 자동 승인
  → 이상 감지 시만 수동 검토
```

#### 사후 품질 모니터링
자동 승인된 콘텐츠의 사후 품질을 추적:
- 발행 후 engagement 메트릭 모니터링
- 독자 피드백/댓글 감성 분석
- 품질 하락 감지 시 자동 승인 조건 강화 또는 일시 중지

## 검토 분석

### 검토 이력 대시보드
- 승인/반려 비율 추이
- 주요 반려 사유 분석
- 품질 점수 추이 (시간별, 소스별, 파이프라인별)
- 검토 소요 시간 분석
- 자동 승인 vs 수동 승인 비율

### 피드백 학습
- 반복되는 피드백 패턴을 감지하여 파이프라인 프롬프트 자동 개선 제안
- 자주 수정되는 유형의 콘텐츠 패턴 분석
- Editor Agent의 프롬프트를 피드백 데이터로 지속 개선
