# UI/UX 설계

## 디자인 원칙

| 원칙 | 설명 |
|------|------|
| **Clarity First** | 복잡한 파이프라인을 직관적으로 시각화 |
| **Progressive Disclosure** | 필요한 정보만 단계적으로 노출 |
| **Direct Manipulation** | 프리뷰에서 직접 편집, 드래그앤드롭 파이프라인 구성 |
| **Real-time Feedback** | 파이프라인 진행, 품질 점수 등 실시간 반영 |
| **Dark Mode First** | 콘텐츠 크리에이터의 사용 환경 고려 |

## 추가 UI/UX 요소 (수준 향상)

### 1. Command Palette (Cmd+K)
- 모든 기능에 키보드로 빠르게 접근
- 자연어로 명령 입력 ("새 소스 추가", "LinkedIn 프리뷰 보기")
- 최근 작업, 즐겨찾기 빠른 접근

### 2. AI Assistant Chat
- 우측 하단 채팅 인터페이스
- "이 콘텐츠의 톤을 더 캐주얼하게 바꿔줘"
- "지난주 LinkedIn 성과 요약해줘"
- 자연어로 파이프라인 제어

### 3. 드래그 앤 드롭 파이프라인 빌더
- 시각적으로 Agent를 배치하고 연결
- 각 Agent의 설정을 인라인으로 조정
- 파이프라인 템플릿 저장/공유

### 4. 콘텐츠 캘린더
```
┌────────────────────────────────────────────────────┐
│  3월 2026                                           │
│  월    화    수    목    금    토    일               │
│  ──── ──── ──── ──── ──── ──── ────               │
│   2    3    4    5    6    7    8                   │
│       📝    📝         📝                           │
│       LI    Blog       LI,X                        │
│   9    10   11   12   13   14   15                 │
│        📝        📝         📝                      │
│        LI        Blog       IG                     │
└────────────────────────────────────────────────────┘
```
- 발행 스케줄을 캘린더 뷰로 시각화
- 드래그로 발행일 변경
- 플랫폼별 색상 구분

### 5. 토스트 알림 & 실시간 배지
- 파이프라인 완료, 검토 요청, 발행 성공/실패 알림
- 브라우저 Push Notification
- 이메일/Slack/Telegram 웹훅 알림

### 6. 온보딩 위저드
- 첫 사용 시 단계별 가이드
- 소스 추가 → 파이프라인 선택 → 첫 콘텐츠 생성 체험
- 인터랙티브 튜토리얼

### 7. 템플릿 갤러리
- 소스 구성 템플릿 (Tech Blogger, Marketing Agency 등)
- 파이프라인 템플릿
- 프롬프트 템플릿
- 커뮤니티 공유 템플릿

### 8. 키보드 단축키
| 단축키 | 동작 |
|--------|------|
| `Cmd+K` | Command Palette |
| `Cmd+Enter` | 승인 |
| `Cmd+Shift+Enter` | 승인 + 즉시 발행 |
| `←` `→` | 이전/다음 검토 항목 |
| `1-5` | 플랫폼 탭 전환 |
| `Cmd+P` | 프리뷰 모드 전환 |

### 9. Collaborative Features (SaaS 확장)
- 팀 멤버 초대 및 역할 설정 (Admin, Editor, Reviewer)
- 댓글 및 멘션
- 승인 워크플로우 (팀장 최종 승인)
- 활동 로그 및 감사 추적

### 10. 접근성
- WCAG 2.1 AA 준수
- 스크린 리더 지원
- 고대비 모드
- 키보드 네비게이션 완전 지원
